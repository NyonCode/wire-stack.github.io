The WireStack ecosystem for Livewire

Build forms, tables & sortable UIs at lightning speed.

Production-ready forms, searchable tables, drag-and-drop sorting, and a shared core runtime — documented with real screenshots captured straight from the package previews.

Getting Started → Documentation Index

Packages

Four packages, one cohesive runtime.

Compose them together or use them on their own — each builds on the shared core.

Wire Forms →

Standalone forms, layouts, validation, and nested repeaters.

Wire Table →

Searchable tables, actions, filters, exports, notifications, and responsive states.

Wire Sortable →

Row and column reordering built on top of the table runtime.

Wire Core →

Actions, widgets, modals, notifications, plugins, and shared foundations.

Wire Panels →

One entity declared once — its pages, its place in the menu, and its URLs.

Wire Admin →

The optional shell: a layout and a sidebar over everything registered.
