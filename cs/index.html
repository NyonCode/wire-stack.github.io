Ekosystém WireStack pro Livewire

Stavějte formuláře, tabulky & sortable UI bleskovou rychlostí.

Produkčně připravené formuláře, vyhledávatelné tabulky, drag-and-drop řazení a sdílený core runtime — dokumentované reálnými screenshoty pořízenými přímo z náhledů balíčků.

Začínáme → Rozcestník dokumentace

Balíčky

Čtyři balíčky, jeden soudržný runtime.

Skládejte je dohromady nebo je používejte samostatně — každý staví na sdíleném core.

Wire Forms →

Samostatné formuláře, layouty, validace a vnořené repeatery.

Wire Table →

Vyhledávatelné tabulky, akce, filtry, exporty, notifikace a responzivní stavy.

Wire Sortable →

Přeřazování řádků a sloupců postavené nad runtime tabulky.

Wire Core →

Akce, widgety, modály, notifikace, pluginy a sdílené foundations.

Wire Panels →

One entity declared once — its pages, its place in the menu, and its URLs.

Wire Admin →

The optional shell: a layout and a sidebar over everything registered.
